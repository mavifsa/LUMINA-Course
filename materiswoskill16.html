Core Structure Axiom

Inversion in Conditionals = Hapus If, Lalu Pindahkan Should / Were / Had ke Depan Subject.

Mekanismenya sama dengan inversi negatif: auxiliary berpindah ke depan subject. Bedanya, di sini if wajib dihapus, dan hanya klausa pengandaian yang memuat should, were, atau had yang bisa diinversi.

Asal Mula: Dari Kalimat Pengandaian ke Inversi

Dua langkah saja: hapus if, lalu pindahkan auxiliary ke depan subject.

Contoh Type 3 (had + V3)
Conditional biasa
If Nanang had managed his friends, he would have been ready.
Langkah 1: hapus if
If Nanang had managed his friends, ...
Langkah 2: pindahkan had ke depan subject
Had Nanang managed his friends, he would have been ready.
Had + S + V3
If tidak dihapus (salah)
❌ If had Nanang managed his friends, he would have been ready.
  • Had sudah ada di klausa pengandaian, jadi bisa langsung berpindah.
  • Klausa utama (he would have been ready) tidak berubah.
  • Makna kalimat tetap sama dengan versi memakai if, tetapi lebih formal.

Langkah Cepat: Bisa Diinversi atau Tidak?

1. Klausa if memuat should / were / had? Jika tidak → tidak bisa diinversi (kecuali Type 2 verbal, lihat langkah 4).

2. Hapus if.

3. Pindahkan aux ke depan subject: Should + S + V1 | Were + S + complement | Had + S + V3

4. Type 2 dengan verb biasa (V2) → Were + S + to V1.

5. Negatif: not diletakkan setelah subject (Had Nanang not managed ...).

⚠️ Kesalahan Umum (Common Pitfalls)

Pitfall #1 If Tidak Dihapus

Inversi dan if tidak boleh muncul bersamaan.

❌ If were PIBI 74 ready for the trip, ...

✓ Were PIBI 74 ready for the trip, they would enjoy it.

Pitfall #2 Type 2 Verbal Tanpa Were

Verb V2 tidak bisa langsung dipindah, dan do-support tidak berlaku.

❌ Canceled Prof. Uceng the class, ...

❌ Did Prof. Uceng cancel the class, ...

✓ Were Prof. Uceng to cancel the class, the students would be happy.

Pitfall #3 Bentuk Verb Salah Setelah Aux

Should + V1, Had + V3, Were + complement.

❌ Should we went to Black Canyon, ...

✓ Should we go to Black Canyon, ...

❌ Had Nanang manage his friends, ...

✓ Had Nanang managed his friends, ...

Pitfall #4 Negatif Dikontraksi di Depan

Gunakan not setelah subject, bukan kontraksi di awal kalimat.

❌ Hadn't Nanang managed his friends, ...

✓ Had Nanang not managed his friends, he would not have been ready.

Golden Rule

Aturan Emas Inversi Conditional

Seperti inversi negatif, auxiliary berpindah ke depan subject. Bedanya, if wajib dihapus dan hanya tiga kata yang bisa dipindah.

Aturan 1 Kata hubung IF wajib dihapus
✓ If we should go to Black Canyon for grilling, ... → Should we go to Black Canyon for grilling, ...
❌ If should we go to Black Canyon for grilling, ...
Aturan 2 Hanya Should, Were, atau Had yang bisa dipindah

Jika klausa if tidak memuat salah satu dari tiga kata ini, inversi tidak bisa dilakukan.

❌ If we go to Black Canyon, we will swim in the river. → Go we to Black Canyon ...
Type 1 biasa (present simple) tidak memiliki should, were, atau had.
❌ If Nanang studies hard, he will pass. → Studies Nanang hard ...
Hal yang Tidak Berubah
  • Klausa utama tetap sama (will, would, would have).
  • Makna kalimat tetap sama dengan versi memakai if, tetapi gaya lebih formal.
  • Koma tetap memisahkan klausa pengandaian dari klausa utama.
  • Were dipakai untuk semua subject, termasuk I, he, she, it.

Ringkasan Pola

Type 1 : If S should V1   → Should + S + V1

Type 2 : If S were Comp  → Were + S + Comp

Type 3 : If S had V3    → Had + S + V3

Syarat  : If dihapus, aux pindah ke depan subject

Conditional Types

Tiga Tipe Conditional yang Bisa Diinversi

Tiap tipe punya makna dan kata kunci inversi yang berbeda.

Type 1 Future Condition (kondisi nyata, mungkin terjadi)

Pengandaian yang mungkin terjadi di masa kini atau masa depan. Bentuk biasanya If + present simple dan tidak bisa diinversi. Inversi hanya berlaku pada varian should (lebih formal, menyiratkan kemungkinan yang lebih kecil). Klausa utama biasanya will, can, may, atau kalimat perintah.

Asal
If we should go to Black Canyon for grilling, we will swim in the river.
Inversi
Should we go to Black Canyon for grilling, we will swim in the river. ⇒ Should + S + V1
Should you need help, please call me. (klausa utama berupa perintah)
Type 2 Present Unreal (berlawanan dengan fakta masa kini)

Mengandaikan sesuatu yang tidak nyata atau berlawanan dengan fakta saat ini. Klausa if memakai were (atau V2), klausa utama would + V1. Setelah were bisa berupa adjective, noun, prepositional phrase, atau Ving.

Asal
If PIBI 74 were ready for the trip, they would enjoy it.
Inversi
Were PIBI 74 ready for the trip, they would enjoy it. ⇒ Were + S + Adj
Were he a teacher, he would explain it differently. (Were + S + noun)
Were she studying abroad, she would learn faster. (Were + S + Ving)
Type 3 Past Unreal (berlawanan dengan fakta masa lalu)

Mengandaikan sesuatu yang berlawanan dengan apa yang sebenarnya terjadi di masa lalu, sering menyiratkan penyesalan atau hasil yang berbeda. Klausa if memakai had + V3, klausa utama would have + V3.

Asal
If Nanang had managed his friends, he would have been ready.
Inversi
Had Nanang managed his friends, he would have been ready. ⇒ Had + S + V3
Had the students been informed earlier, they would have attended. (Had + S + been + V3 untuk pasif)

Special Cases

🔑 Kasus Khusus: Were + to V1 dan Bentuk Negatif

1. Type 2 dengan Action Verb (V2)

Jika klausa pengandaian Type 2 memakai verb biasa (V2) dan tidak ada were, kita wajib memunculkan Were dan mengubah verb menjadi to + V1.

Asal
If Prof. Uceng canceled the class, the students would be happy.
✓ Were Prof. Uceng to cancel the class, the students would be happy. ⇒ Were + S + to V1
❌ Canceled Prof. Uceng the class, the students would be happy.
❌ Did Prof. Uceng cancel the class, the students would be happy.
❌ Were Prof. Uceng cancel the class, the students would be happy. (to hilang)
Contoh lain
If the committee announced the results today, ... → Were the committee to announce the results today, ...
2. Bentuk Negatif

Pada inversi, not diletakkan setelah subject. Bentuk kontraksi di awal kalimat (Hadn't, Weren't) tidak dipakai.

✓ Had Nanang not managed his friends, he would not have been ready.
✓ Were Prof. Uceng not to cancel the class, the students would be unhappy.
✓ Should we not go to Black Canyon, we will stay at the campus.
❌ Hadn't Nanang managed his friends, he would not have been ready.
3. Should vs Were: Jangan Tertukar

Should diikuti V1 langsung, sedangkan Were pada verb biasa diikuti to + V1.

✓ Should we go to Black Canyon, ...
❌ Should we to go to Black Canyon, ...
✓ Were we to go to Black Canyon, ...

Ringkasan Aturan

1. Type 2 verbal (V2) → Were + S + to V1 (tanpa do-support).

2. Negatif → aux + S + not + ... (tanpa kontraksi di awal).

3. Should + V1  |  Were + S + Comp / to V1  |  Had + S + V3.
